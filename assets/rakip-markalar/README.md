# Rakip Firma Marka Varlıkları (Dashboard Kartları)

Dashboard'daki ASELSAN/SSB/SSTEK/Havelsan kartlarında kullanılan logo ve renklerin kaynağı.

| Firma | Renk | Kaynak | Logo notu |
|---|---|---|---|
| ASELSAN | `#013088` | aselsan.com resmi favicon (android-chrome-512x512.png) | Kare, kurumsal amblem |
| SSB | `#E31513` | ssb.gov.tr resmi logo dosyası | Tam logodan (yazı+amblem) sadece amblem kısmı kırpıldı |
| SSTEK | `#0951F8` | sstek.com.tr sitesindeki footer logo + Tailwind CSS'teki vurgu rengi | Gerçek kelime logosu yok, ikon markası da yok — kendi marka mavisi üzerine beyaz "SSTEK" kelime logosu yerleştirilerek kare rozet oluşturuldu |
| Havelsan | `#B80A2E` | Wikimedia Commons (Havelsan_logo.svg) | Tam logodan (yıldız ikon + "HAVELSAN" yazı) sadece yıldız ikon kısmı kırpıldı |

Kullanılan (işlenmiş, kare) dosyalar `frontend/public/rakip-logos/` altında.
