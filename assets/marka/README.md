# Ulak Haberleşme Marka Varlıkları

Kaynak: ulakhaberlesme.com.tr/kalite-yonetimi/kurumsal-kimlik/ (Kasım 2024 kurumsal kimlik kılavuzu)

## Renkler
- Ana renk (açık mavi): `#5CCAE8`
- İkincil renk (koyu gri): `#5B5C5E`
Bu renkler `src/brand_colors_data.json` içinde "ulak haberlesme" anahtarı altında kayıtlı;
UI paleti `src/brand_colors.py` içindeki `palet_uret()` ile buradan otomatik türetiliyor.

## Logo dosyaları
- `Ulak_Logo.svg` — kare/ikon formatlı vektör logo (favicon ve küçük ikon alanlarında kullanılıyor: `frontend/public/logo.svg`)
- `ulak_logo.png` — tam renkli geniş logo (beyaz zeminde: `frontend/public/logo.jpg`)
- `ulak_logo_beyaz.png` — tamamen beyaz versiyon (koyu/renkli zeminler için)
- `ulak_logo_mavi_beyaz.png` — beyaz yazı + mavi ikon (koyu zeminler için, ör. sidebar arka planı)
- `ulak_kurumsal_kimlik_kilavuzu_2024.pdf` — resmi kurumsal kimlik kılavuzu (logo kullanım kuralları, güvenli alan, yasak kullanımlar)

Kurala göre logo değiştirilemez/yeniden çizilemez — yalnızca yukarıdaki resmi dosyalar kullanılmalı.
